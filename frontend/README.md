# Tablero Respira GDL

Vistas:
1. **Escuela:** salones con PM2.5 dentro/fuera y % de protección.
2. **Maestro:** semáforo del día, alumnos con asma en el grupo (solo número) y guía de crisis.

Sugerencia: Vite + React + Leaflet + Recharts.

## Diseño

Todo el frontend sigue la [guía de diseño](../docs/diseno/README.md). Importen `src/styles/tokens.css` en `main.jsx` antes que cualquier otro estilo y usen sus variables (`var(--rg-ink)`, `.rg-card`, `.rg-pill`).
