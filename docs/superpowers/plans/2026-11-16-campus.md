# Escuela 3D · plan de implementación

> Ejecución autónoma solicitada por Sergio. Implementación en esta sesión con revisión independiente final.

**Objetivo:** demostrar decisiones escolares en seis aulas isométricas, sin confundir simulación con evidencia real.
**Arquitectura:** motor JavaScript puro, renderer SVG y controles React; estado local separado de API.
**Tecnologías:** React 18, SVG, CSS con tokens existentes, node:test, FastAPI/pytest, PlatformIO.
**Especificación:** `docs/superpowers/specs/2026-11-16-campus-design.md`.

## Restricciones y revisión

Todo en español de México por instrucciones del proyecto. No datos reales, secretos, atribución de IA en commits ni push a main. No afirmar eficacia clínica o medir PM2.5 con MQ. Revisar presupuesto cero, entradas no finitas, cambios durante reproducción, consistencia del contrafactual, controles accesibles y movimiento reducido.
